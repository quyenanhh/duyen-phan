The system's action control — green primary, clay accent for landing-page CTAs.

```jsx
<Button icon="plus">Thêm chi nhánh</Button>
<Button variant="secondary" size="sm">Huỷ</Button>
<Button variant="accent" size="lg" iconRight="arrow-right">Đặt bàn</Button>
```

Sizes 32/40/48px. Press state nudges 1px down (never scales). Use `danger` only for destructive confirmations.
