# UI kit — Trang chủ (public landing)

Single-page brand site, 1280px design width, max content 1200px with 32px gutters.

- `Sections.jsx` — `Nav`, `Hero`, `MenuSection`, `StorySection`, `BranchSection`, `Footer`, `LandingPage`
- `index.html` — renders `LandingPage`; nav links scroll-jump between sections, menu category chips filter visually.

Landing is the ONLY surface allowed to use `--font-serif` (Lora): hero, section headings, wordmark. Body copy stays Be Vietnam Pro.
Photography is not supplied — every image is a dashed clay placeholder (`Photo`). Swap in real photos before use.
