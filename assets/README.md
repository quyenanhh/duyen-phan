- **Icons:** Lucide 0.454 loaded from CDN — see the ICONOGRAPHY section of `readme.md`.
- **Photography:** UI kits use labelled dashed placeholders.

Drop real files here (logo.svg, photos/) and update `readme.md` when they arrive.
