Outline icon wrapper over Lucide — use for every glyph in the system; never hand-draw SVG.

```jsx
<Icon name="leaf" size={18} />
<Icon name="truck" color="var(--info)" title="Đang giao" />
```

Stroke is 1.5 by default (brand rule: thin, no filled icons). Food/nature glyphs preferred where meaningful: leaf, soup, utensils, sprout, truck, store.
